MLBC PROGRESSION TRACKER

Compares each player's edited/projected performance (from the roster export, run through the real ranking engine) against what they actually did on the field, across career / last-3-years / last-year / current. Re-run this every season as new performance exports come in — it's the empirical check on whether the ranker's assumptions hold up, and it surfaces who's trending up or down for trade purposes. Does not modify the ranking engine itself — this is a read-only analysis layer on top of it.

Hitter hand reliability

actual OPS minus the roster export's edited/projected OPS (25% vL + 75% vR blend), grouped by bat hand. A more negative number means the edits overrate that group relative to what they actually produce. Minimum sample size per period shown in parentheses.

Pitcher hand reliability

actual (OBP+SLG allowed) minus the engine's projected W_OPS, grouped by throwing hand. Same idea as above, for pitchers.

Trending down (regression / possible sell candidates)

Last Year performance well below Career baseline, min. sample size in both windows.

Trending up (possible buy-low / breakout)

Last Year performance well above Career baseline, min. sample size in both windows.
